## Getting Started

### Prerequisites

Make sure **Node.js** and **npm** are installed.

### Clone the Repository

```bash
git clone https://github.com/MahmoudMo99/portfolio.git
cd portfolio
```

### Install Dependencies

```bash
npm install
```

### Run Locally

```bash
npm start
```

Open the application at:

```text
http://localhost:4200
```

### Production Build

```bash
npm run build
```

The production build generates optimized application files for deployment.

## Deployment

The portfolio is deployed on **Vercel**.

**Live Website:** https://mahmoud-mohamed-portfolio.vercel.app/
