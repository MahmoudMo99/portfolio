# Mahmoud Mohamed Portfolio

A personal portfolio website built with Angular to showcase my frontend development work, technical skills, professional experience, client feedback, and selected projects.

https://mahmoud-mohamed-portfolio.vercel.app

## Overview

This portfolio presents my work as a Software Engineer and Angular Frontend Developer.

It highlights my experience in building responsive web applications, admin dashboards, RTL interfaces, API-integrated applications, and client-focused frontend projects.

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/MahmoudMo99/portfolio.git
cd portfolio
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
ng serve
```

Open:

```txt
http://localhost:4200
```

### Build

```bash
ng build
```
